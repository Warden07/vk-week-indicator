# WeekClock для ESP8266 D1 Mini

Часы и учебная неделя на дисплее ST7789 240×240. Настройка Wi-Fi с телефона, сохранение сети на плате и подписанные обновления через GitHub. VK-бот и сервер на компьютере не нужны.

**Первая версия для проверки на оборудовании.** Результаты сборки см. в [проверках](docs/VALIDATION.md). Физическая плата и дисплей ещё не испытаны.

Прошивка не содержит Wi-Fi-паролей. Параметры сети вводятся после установки и хранятся на устройстве. Временный пароль настройки показан на дисплее и в USB Serial.

После синхронизации часы продолжают идти без Wi-Fi, пока устройство включено. После потери питания нужен NTP; отдельного RTC с батарейкой в проекте нет. Недели считаются семидневными блоками с 1 сентября и 10 февраля, а не по понедельникам.

## Сборка

```sh
python -m pip install platformio==6.1.18
pio run
pio run -t upload
pio device monitor -b 115200
```

`platformio.ini` выбирает D1 Mini, ESP8266 Arduino Core 3.1.2 и Flash 4 МБ. Для другой платы этот образ не предназначен. При первом подключении проверьте фактический объём Flash.

Исходники также открываются в Arduino IDE: вся папка `firmware/WeekClock_ST7789` должна оставаться вместе. Установите ESP8266 Core 3.1.2 и библиотеки из `platformio.ini`.

## Приватность

В публичный проект входят исходники, документация, сертификаты центров доверия и **открытый** ключ проверки прошивок. **Закрытый ключ подписи, дампы памяти платы и персональные настройки сюда не загружаются.** Подпись не скрывает код: она позволяет плате отклонять чужие обновления.
