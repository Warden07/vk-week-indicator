
# VK Week Indicator

Система отображения учебной недели и времени.

Оборудование:
- ESP8266 D1 Mini
- TFT ST7789 240x240

Программное обеспечение:
- Python Flask
- VK Bot
- HTTP API для ESP8266

Функции:
- Автоматический расчёт учебной недели
- Отображение времени
- Управление через VK
- Получение данных Arduino по Wi-Fi
