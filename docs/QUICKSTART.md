# Первая установка и настройка

## Перед подключением

Нужна D1 Mini **ESP8266 с 4 МБ Flash**, ST7789 240×240 и USB-кабель с передачей данных. Сначала проверьте [распиновку](HARDWARE.md), особенно CS и BLK. Обычную 9-вольтовую «Крону» напрямую к выводам 5V/3V3 подключать нельзя. Для первого теста используйте стабильное питание от USB; автономное питание требует отдельного согласования схемы.

## Установка исходников

1. Распакуйте проект. Сохраните все файлы папки `firmware/WeekClock_ST7789` вместе.
2. В Arduino IDE установите ESP8266 Core 3.1.2. Выберите `LOLIN(WEMOS) D1 R2 & mini`, Flash 4 МБ, FS 1 МБ.
3. Установите Adafruit GFX 1.11.11, Adafruit ST7735 and ST7789 1.10.4, WiFiManager 2.0.17 и их зависимости. Либо используйте PlatformIO: `pio run -t upload`.
4. Откройте `WeekClock_ST7789.ino`, выберите COM-порт, выполните проверку и загрузку.
5. Откройте Serial Monitor на 115200 бод. Пароль вашего Wi-Fi в код вписывать не нужно.

Для установки готового `.bin` используется esptool, адрес начала приложения ESP8266 — `0x0`. Укажите реальный COM-порт:

```sh
python -m esptool --chip esp8266 --port COM5 --baud 115200 write_flash --flash_size 4MB 0x0 WeekClock_ST7789-v1.0.0-d1-mini.bin
```

Команда предназначена только для ESP8266. Не используйте образ для ESP32 или Arduino Uno. Полное стирание Flash не требуется для обычного обновления.

## Настройка с одного телефона

1. Узнайте в настройках телефона имя и пароль его точки доступа. Пока оставьте раздачу выключенной.
2. Подключитесь телефоном к Wi-Fi `WeekClock-…`. Пароль этой временной сети показан на дисплее платы и в Serial. Если телефон сообщает «нет интернета», оставайтесь подключённым.
3. Откройте браузер и адрес `http://192.168.4.1`. Нажмите **Configure WiFi**.
4. В поля **SSID** и **Password** вручную введите имя и пароль будущей раздачи телефона. Она выключена, поэтому в списке найденных сетей её может не быть. Нажмите **Save**.
5. Отключитесь от WeekClock и включите раздачу телефона в режиме **2,4 ГГц**. Плата повторит подключение автоматически.
6. После получения времени появятся часы и учебная неделя. GitHub проверяется автоматически, если он доступен.

Для обычного домашнего роутера выберите его сеть в списке, введите пароль и сохраните. Раздавать интернет с телефона тогда не требуется.

## Дальнейшая работа

При той же сети повторно вводить пароль не нужно. Интернет можно выключить после синхронизации, но после потери питания потребуется снова получить время.

Для смены владельца включите плату без прежней сети и подождите минуту: появится точка настройки. Портал работает пять минут. Чтобы открыть его заново, перезапустите плату или отправьте `wifi` в Serial с окончанием строки. Команда `update` запускает проверку GitHub после подключения и синхронизации.

Если GitHub недоступен, устройство продолжает показывать время и неделю. Ошибка обновления не означает, что нужно вводить пароль Wi-Fi заново.
