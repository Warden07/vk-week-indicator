# Прошивка WeekClock

Откройте `WeekClock_ST7789.ino` вместе с `AppConfig.h`, `Calendar.h` и `Trust.h` из этой папки. Общая инструкция — [первая установка](../../docs/QUICKSTART.md).

`AppConfig.h` содержит номера GPIO, версию и публичный адрес обновлений. `Trust.h` содержит только открытые данные проверки, его нужно сохранить при переносе проекта. Пароли вводятся через портал на плате.

Для будущего выпуска увеличьте `FW_BUILD` и `FW_VERSION`. Образ должен быть подписан тем же закрытым ключом, которому соответствует встроенный открытый ключ. Если ключ утрачен, новый ключ устанавливается первой прошивкой через USB.
